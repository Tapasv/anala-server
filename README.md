# ANALA Server

Backend API for ANALA, an AI-powered conversational platform built with Node.js, Express, PostgreSQL, Prisma, and OpenAI.

---

## Tech Stack

- Node.js
- Express.js
- PostgreSQL
- Prisma ORM
- JWT Authentication
- OpenAI API
- Docker (Coming Soon)

---

## Features

- JWT Authentication
- Secure Access & Refresh Tokens
- AI Conversations
- Conversation History
- User Profile Management
- REST API
- PostgreSQL Database
- Prisma ORM

---

## Installation

```bash
git clone https://github.com/Tapasv/anala-server.git

cd anala-server

npm install
```

Create a `.env` file using `.env.example`.

Run the server

```bash
npm run dev
```

Refer to `.env.example`.
